# flowershop
Not your average flower shop. A gothic-inspired Flutter application where even Wednesday Addams might find the perfect bouquet.

## Installation & Setup

### Prerequisites
- Flutter SDK
- Android Studio or Visual Studio Code
- Android emulator or physical Android device
- Internet connection

### Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/annemievdc/flowershop.git
   ```

2. Navigate to the project directory:
   ```bash
   cd flowershop
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```

### Firebase Configuration

This application connects to an existing Firebase Cloud Firestore database.

No additional Firebase setup or account is required to browse the flower catalogue.

The database provides read-only access to flower products. Modifying the catalogue is restricted.

**Note:** An internet connection is required to retrieve product data.
